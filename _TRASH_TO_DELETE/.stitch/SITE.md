# Stitch Build Loop — T04 ANND Management App

## Project Vision

An authoritative, precision-engineered administrative dashboard for Trường Đại học An ninh nhân dân (T04). This tool manages teaching workload norms and scientific research quotas for faculty (nhà giáo) under Thông tư 108/2025/TT-BCA. The design must project institutional trust, data clarity, and measured authority — not consumer friendliness.
